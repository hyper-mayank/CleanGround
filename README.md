# ⚡ CleanGround Pro — Issue Tracker & Support

Welcome to the official issue tracker and bug reporting hub for **CleanGround Pro**.

> 💡 **CleanGround Pro** is an enterprise-grade multi-threaded entity & ground item sweeper built for Bukkit, Spigot, Paper, Purpur, and Folia server networks.

---

### 🐛 Reporting a Bug or Issue

If you encounter an issue, bug, or performance anomaly:
1. Check the [Existing Issues](https://github.com/hyper-mayank/CleanGround/issues) to make sure it hasn't already been reported.
2. [Open a New Issue](https://github.com/hyper-mayank/CleanGround/issues/new) and include:
   - Server software and exact version (e.g., Paper 1.20.4 build #498, Folia 1.20.4).
   - Java version (`java -version`).
   - CleanGround configuration (`config.yml`).
   - Relevant server log / stacktrace (use [Pastebin](https://pastebin.com) or [mclo.gs](https://mclo.gs)).
   - Steps to reproduce the bug.

---

### 💡 Feature Requests & Inquiries

Have an idea for a feature or optimization?
- Please open an issue tagged with `[Feature Request]` in the title.
- Detail the use case and expected behavior.

---

### 🛡️ Security Vulnerabilities

To report sensitive security issues or exploits, please submit an issue with `[SECURITY]` in the title or contact the maintainer directly.
